### Requirements

DeepSeek Bridge connects **Claude Code** to **DeepSeek** so Claude can offload
token-heavy, file-based chores to a far cheaper model.

You need:

- **Claude Code** installed and running in this editor.
- A **DeepSeek API key** — free to create at
  [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys).

Your workspace files are processed locally and sent to DeepSeek's API to perform
each task. See the README's **Data handling & privacy** section for details.
