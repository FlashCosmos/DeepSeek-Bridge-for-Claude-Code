### Reconnect & try it

Claude Code loads MCP servers when it connects, so after saving you need to
reconnect once:

- Run **DeepSeek Bridge: Reconnect Claude Code** from the Command Palette, or
- Run `/mcp` inside Claude Code, or reload the window.

Then just ask Claude to do something big:

> *"Refactor everything in `src/` to use the new API."*

Claude will delegate the heavy lifting to DeepSeek automatically. Watch it happen
live in the sidebar's **Console** tab, and see your savings in **History**.
