### Add your API key

1. Open the **DeepSeek Bridge** sidebar (the ⚡ icon in the Activity Bar).
2. Paste your DeepSeek API key into the **API Key** field.
3. Click **Save & Connect**.

Your key is stored in VS Code's encrypted SecretStorage and mirrored to
`~/.claude.json` (the file Claude Code reads). On headless remotes without a
keyring, the `~/.claude.json` copy is the source of truth.
